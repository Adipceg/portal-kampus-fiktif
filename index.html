🔍 Informasi Kerentanan Yang Ditanam Secara Sengaja:

  • 1. Stored XSS (Cross-Site Scripting): Pada menu Forum Diskusi, input pesan pengguna disimpan dan dirender langsung menggunakan innerHTML tanpa sanitasi. Coba kirim: <b style="color:red">XSS Alert</b> <img src=x onerror="alert('Stored XSS Berhasil!')">.
  • 2. Validasi Berkas Lemah (Unrestricted File Upload): Pada menu Unggah Tugas, form mengizinkan berkas apapun tanpa filter ekstensi (misal: .php, .html, .exe, .sh) dan nama berkas ditampilkan langsung.
  • 3. IDOR / Kontrol Akses Lemah: Pada menu Lihat Nilai, mahasiswa dapat melihat transkrip nilai mahasiswa lain cukup dengan mengganti parameter ID Mahasiswa tanpa verifikasi otorisasi sesi.
